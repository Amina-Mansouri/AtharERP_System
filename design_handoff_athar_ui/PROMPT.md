# البرومت — الصقه في Claude Code داخل مجلد المستودع

> افتح `ERP Wireframes.dc.html` في المتصفح بجانبك أثناء العمل، وأرفق مجلد
> `design_handoff_athar_ui/` داخل المستودع حتى يقرأ Claude Code الملفات.

---

## البرومت الرئيسي (انسخ من هنا)

```
أنت تعمل على مستودع AtharERP_System — نظام ERP بـ ASP.NET Core MVC 8 + EF Core +
ASP.NET Core Identity، عربي RTL بالكامل، هوية بنّية/عنبرية، العملة الدينار الليبي.

في المجلد design_handoff_athar_ui/ توجد حزمة تصميم كاملة:
- README.md — نظرة عامة وخطة العمل
- SCREENS.md — مواصفة تفصيلية لـ ٢١ شاشة (قياسات، ألوان، أعمدة، نصوص، حالات)
- BACKEND.md — كل تعديل مطلوب في المنطق وقاعدة البيانات
- ERP Wireframes.dc.html — المراجع البصرية (كل شاشة لها رقم 1a … 1u)

اقرأ الثلاثة أولاً بالكامل قبل أي كود.

مهمتك: تحويل واجهات هذا المستودع إلى الشكل الموصوف في الحزمة — بدقة، شاشة شاشة،
بلا إسقاط أي عنصر. ملفات HTML في الحزمة مراجع تصميم فقط: أعِد بناءها كـ Razor Views
باستخدام Bootstrap 5 وjQuery الموجودين في wwwroot/lib، لا تنسخ الـ HTML كما هو ولا
تُدخل أي حزمة JS/CSS جديدة، ولا تستخدم ViewModels (سياسة المستودع: تمرير الـ Models
مباشرة إلى الـ Views، واستخدام [Bind] في الـ Controllers).

ملاحظة مهمة: ملفات Views/**/*.cshtml غير موجودة في المستودع حالياً، فمعظم العمل هو
إنشاء الـ Views وطبقة العرض. الكيانات الـ٥٧ والـ Services موجودة — استخدمها ولا تُنشئ
كيانات جديدة إلا ما نصّ عليه BACKEND.md صريحاً.

ابدأ بالمرحلة ١ فقط ثم توقّف واعرض النتيجة:

المرحلة ١ — الأساس المشترك:
1. wwwroot/css/site.css: أضف طبقة توكنز (:root) بالقيم الموجودة في SCREENS.md §0
   (الألوان، الخطوط، الحدود الشعرية، نصف القطر 4px، مقاسات النص)، وأنماط:
   .app-topbar, .app-sidebar, .nav-item(+.active), .page-head, .kicker, .stat-strip,
   .filter-bar, .data-table, .tag(+.tag-accent), .btn-line(+.btn-line-accent),
   .progress-hair, .side-panel, .pager. لا تحذف أنماط site.css القائمة، أضف فوقها.
2. Views/Shared/_Layout.cshtml: شريط علوي بارتفاع 46px (الشعار + بحث شامل + جرس
   بأيقونة Lucide وعدّاد ذهبي + صورة المستخدم + اسم الدور)، وقائمة جانبية يمنى بعرض
   186px بالبنية الثابتة الآتية بهذا الترتيب حرفياً:
   لوحة المعلومات · الإشعارات (مع عدّاد غير المقروء) ·
   ٠١ الصلاحيات والمصادقة: المستخدمون، الأدوار والصلاحيات، الأقسام ·
   ٠٢ إدارة المشاريع: العملاء، المشاريع، المهام، التكاليف، الجدول الزمني ·
   ٠٣ المواقع والعمليات: المواقع، التقارير اليومية، الفحوصات، المقاولون، الصيانة، طلبات التوريد.
   البند النشط: خلفية rgba(182,130,53,.07) + شريط 2px ذهبي على الحافة اليمنى.
   أخفِ أي بند لا يملك المستخدم صلاحيته (استخدم PermissionService).
3. Views/Shared/Partials: _PageHead, _StatStrip, _FilterBar, _DataTable, _Tag,
   _SidePanel, _Pager — بحيث تبني كل شاشة لاحقة من هذه القطع.
4. ViewComponent باسم NavCounters يجلب: عدد الإشعارات غير المقروءة، الاعتمادات
   المعلقة، التقارير اليومية الناقصة، طلبات التوريد المعلقة — باستعلام واحد مُخزَّن
   مؤقتاً 60 ثانية.

عند الانتهاء: اذكر ما أنشأته، وأرِني _Layout.cshtml وsite.css، ثم انتظر موافقتي
قبل المرحلة ٢.
```

## البرومتات التالية (واحد لكل مرحلة، بعد موافقتك على السابقة)

**المرحلة ٢ — الوحدة ٠١**
```
نفّذ شاشات الوحدة ٠١ حسب SCREENS.md: 1a تسجيل الدخول، 1b لوحة المعلومات،
1c المستخدمون، 1d ملف المستخدم، 1e الأدوار والصلاحيات، 1f الأقسام.
التزم بالضبط بأعمدة الجداول وترتيبها، وبنود شريط الأرقام، وأسماء التبويبات وعدّاداتها،
والمرشّحات، ونصوص الأزرار كما في المواصفة. Controllers: AccountController و
AdminController الموجودان — أضف الـ actions الناقصة فقط ولا تعد كتابة المنطق القائم.
نفّذ من BACKEND.md البنود: ٦ (إخفاء اسم العميل)، ٨ (الصلاحيات الفعلية)، ١٥ (سجل التغييرات).
```

**المرحلة ٣ — الإشعارات**
```
نفّذ 1t (شاشة الإشعارات) و1u (قائمة الجرس المنسدلة) حسب SCREENS.md،
ونفّذ من BACKEND.md البنود ٢ و٣ و٤ و٥ (حقول الإشعار الجديدة، جدول تفضيلات الإشعارات،
إطلاق الأحداث الأحد عشر، عدّادات القائمة). أنشئ الترحيل (migration) بأمر
dotnet ef migrations add notifications_ui وأرِني الـ migration قبل تطبيقه.
```

1j المهام، 1k التكاليف، 1l الجدول الزمني — حسب SCREENS.md.
ونفّذ من BACKEND.md البنود ٧ (التحقق من مجموع الأوزان ١٠٠٪ مع المؤشر الحي)،
١٠ (عدّادات التبويبات)، ١١ (الإجراءات الجماعية)، ١٢ (التصدير).
تنبيه: المشاريع الفرعية تظهر متداخلة تحت الرئيسي في نفس الجدول (بادئة ↳)، لا في قائمة منفصلة.

1p الفحوصات، 1q المقاولون، 1r الصيانة، 1s طلبات التوريد — حسب SCREENS.md.

بأي عنصر لم يُنفَّذ أو نُفِّذ مختلفاً ولماذا. ثم شغّل التطبيق وتأكد أن كل بنود
القائمة الجانبية تفتح صفحة عاملة بلا استثناء.

## نصائح لتشغيل أفضل
- اطلب منه **مرحلة واحدة في كل مرة** وراجع بعدها — ٢١ شاشة في طلب واحد تُفقد التفاصيل.
- إن انحرف عن المواصفة: «راجع SCREENS.md قسم 1h — الأعمدة عندك ناقصة/مختلفة الترتيب».
- بعد كل مرحلة: «اعرض لقطة أو HTML الصفحة الناتجة وقارنها بالمرجع رقم …».
- لا تسمح بإدخال Tailwind أو React أو أي حزمة جديدة — Bootstrap 5 وjQuery فقط.
