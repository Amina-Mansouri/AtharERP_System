# جرد الشاشات الفعلي

كل شاشة موجودة الآن في الكود، وماذا تفعل بالضبط — من مراجعة فعلية للـViews والـControllers، لا من خطة.

---

## ٠١ الصلاحيات والمصادقة

| الشاشة | ماذا تفعل |
|---|---|
| `Account/Login` | بطاقة دخول موسّطة بلا شريط جانبي: بريد + كلمة مرور + "تذكّرني" + رابط نسيت كلمة المرور |
| `Account/ForgotPassword` | فورم بريد فقط لطلب رابط إعادة تعيين |
| `Account/ResetPassword` | كلمة مرور جديدة + تأكيد، مع رمز/بريد مخفيين من رابط الإحالة |
| `Account/AccessDenied` | رسالة "غير مصرح لك" + زر رجوع للرئيسية |
| `Admin/Users` | دليل الموظفين (مدير النظام فقط) — دائرة إحصائية (نشط/عقد قريب الانتهاء/موقوف/آخر)، شريط فلاتر (رقم وظيفي، إدارة، قسم، رتبة، مسار، دور، حالة)، جدول مُرقَّم (الاسم، الرقم الوظيفي، هاتف أقرب الأقارب، الإدارة، القسم، الرتبة، المسار، الدور، نهاية العقد، الحالة). النقر على الصف يفتح `UserDetails` |
| `Admin/CreateUser` | فورم موظف جديد: بيانات شخصية، كلمة مرور، اختيار مسار→رتبة (قوائم متتالية بجافاسكريبت)، إدارة→قسم متتاليان، الدور، الراتب وتواريخ العقد، رفع صورة شخصية وصورة عقد، خريطة Leaflet لتحديد موقع الحضور المتوقع + النطاق المسموح |
| `Admin/UserDetails` | مساحة عمل الموظف الواحد. رأس بالصورة وزر تفعيل/تعطيل. تنبيهات تلقائية لاقتراب/انتهاء العقد. ٦ تبويبات: **البيانات** (فورم قابل للتعديل، مقفل حتى الضغط على "تعديل")، **الصلاحيات الفعلية** (قراءة فقط، صلاحيات دوره)، **المستندات** (شبكة مستندات + رابط لإدارة كاملة)، **سجل العقود** (أرشيف العقود السابقة)، **موقع الحضور** (عرض فقط)، **سجل التغييرات** (سجل تدقيق) |
| `Admin/Roles` | لوحتان: يسار قائمة الأدوار (نوع/حالة/عدد صلاحيات/عدد موظفين)، يمين صلاحيات الدور المحدد مجمَّعة بالوحدة مع عدّاد حي. مودال مشترك للإنشاء/التعديل — أسماء الأدوار الأساسية غير قابلة للتغيير |
| `Admin/Departments` | شجرة إدارات/أقسام قابلة للطي + لوحة تفاصيل العقدة المحددة (الأقسام التابعة، عدد الموظفين، التفعيل) + مودال إنشاء/تعديل |
| `Admin/RanksAndTracks` | بطاقة لكل مسار وظيفي مع جدول رتبه (الرمز، الاسم عربي/إنجليزي، الراتب الأساسي، الترتيب) + مودالات إنشاء/تعديل للمسارات والرتب |

## ٠٢ المشاريع

| الشاشة | ماذا تفعل |
|---|---|
| `Projects/Index` | قائمة مشاريع بدائرة إحصائية + شريط فلاتر + جدول هرمي (مشاريع رئيسية بصفوف فرعية قابلة للطي، رمز/اسم/عميل/نوع/ميزانية/نسبة إنجاز/تسليم/تأخير/حالة) |
| `Projects/Details` | **المساحة المركزية للمشروع** (٩٣٧ سطرًا، أكبر View بالتطبيق). رأس بأزرار إيقاف/إلغاء/إعادة تفعيل/حذف. تبويبات: **بيانات المشروع**، **مراحل المشروع** (جدول مراحل + مهام كل مرحلة قابلة للتوسيع + تفعيل قوالب)، **التكليفات** (بطاقات تكليف: مهندسون، تعليق/إلغاء/حذف، فورم إنشاء تكليف جديد)، **وثائق المشروع**، **الجدول الزمني** (Gantt بسيط)، و**المشاريع الفرعية** (للمشروع الرئيسي فقط) |

## عبر-المشاريع (تظهر تحت ٠٢/٠٣ في القائمة)

| الشاشة | ماذا تفعل |
|---|---|
| `ProjectStages/Overview` | متابعة مراحل عبر كل المشاريع — اختيار مشروع فيعرض دائرة + جدول كل مراحله |
| `ProjectAssignments/Overview` | متابعة التكليفات عبر المشاريع — فلاتر مشروع/مرحلة + دائرة + تبويبات حالة المهام + بطاقتان لكل تكليف (بيانات التكليف ومهامه مع اعتماد/رفض، ومستندات مقترحات التصميم لمهامه مع اعتماد/رفض منفصل) |
| `ProjectAssignments/MyAssignments` | تكليفات المستخدم الحالي فقط — بطاقات بسيطة بروابط لمهامه |
| `ProjectTasks/MyTasks` | جدول بسيط لمهام المستخدم الحالي |
| `ProjectTasks/Edit` | مساحة عمل المهمة الواحدة — تبويبان: **بيانات المهمة** (حقول مقسَّمة حسب الصلاحية: عامة/تعديل تواريخ/مالية، حظر/إلغاء حظر، قائمة To-Do تقود نسبة الإنجاز، المكلَّفون بنسبة المساهمة)، **مقترحات التصميم** (رفع + قائمة مع اعتماد/رفض) |
| `ProjectStages/Edit` | فورم تعديل مرحلة واحدة (الوزن مقفل بعد الإنشاء، مساحة وسعر متر وقيمة محسوبة، مهندس مسؤول، حالة تلقائية للقراءة فقط) |
| `StageTemplates/Index`, `Create`, `Edit` | إدارة قوالب المراحل القابلة لإعادة الاستخدام — لا رابط جانبي، تُفتَح فقط من داخل تفاصيل المشروع |

## ٠٣ المواقع

| الشاشة | ماذا تفعل |
|---|---|
| `Sites/Index` | قائمة مواقع بدائرتين إحصائيتين (حالة + تنبيهات) + جدول (رمز/اسم/مشروع/عنوان/مقاول نشط/تاريخ بدء/إنجاز/تقرير اليوم/احتياجات/حالة) |
| `Sites/Details` | مركز الموقع الواحد — رأس بحالة + تعديل + إيقاف/استئناف، شريط إحصائي، بطاقة معلومات، "روابط سريعة" للشاشات الفرعية الست، قائمة مراحل عمل بأشرطة تقدم + فورم إضافة مرحلة |
| `Sites/Create`, `Edit` | فورم موقع: رمز اختياري، اسم، مشروع، وصف/متطلبات، بحث عنوان + خريطة Leaflet، تواريخ |
| `Sites/EditOperation` | تعديل مرحلة عمل واحدة (اسم/ترتيب/تواريخ/إنجاز) |
| `SiteContractors/Index` | جدول ربط مقاولين بموقع (أو عرض عام لكل المواقع)، فورم ربط مقاول موجود أو إنشاء وربط مقاول جديد |
| `SiteContractors/Edit` | تعديل تخصص/حالة/تواريخ ارتباط مقاول بموقع |
| `SiteDailyReports/Index`, `Details` | تقارير يومية مفلترة بالتاريخ؛ التفاصيل تعرض شبكة بيانات + معرض صور بحذف فردي |
| `SiteChecks/Index` | جدولا فحوصات جودة وسلامة لموقع، مع اعتماد ضمني بقائمة نتيجة منسدلة |
| `SiteMaintenance/Index`, `Edit` | طلبات صيانة الموقع + فورم إضافة/تعديل |
| `SiteDocuments/Index` | رفع وعرض مستندات موقع مصنَّفة (خريطة معتمدة/عقد مقاول/تقرير جودة/تقرير سلامة/تقرير يومي/أخرى) |
| `SiteSupplyRequests/Index` | جدول طلبات توريد موقع مع تحديث حالة منسدل (معلق/معتمد/تم التسليم/مرفوض) |

## بوابة المقاولين الخارجيين (نظام دخول منفصل تمامًا)

| الشاشة | ماذا تفعل |
|---|---|
| `ContractorPortal/Login` | دخول منفصل للمقاولين (مخزن اعتماد خاص بهم، ليس `ApplicationUser`) |
| `ContractorPortal/Dashboard` | مواقع المقاول نفسه فقط — دائرة + جدول، بلا شريط جانبي للنظام |
| `ContractorPortal/SiteDetails` | نسخة مقاول من صفحة الموقع: جدول مراحل عمل بإدخال تواريخ فعلية (يُغيّر الحالة تلقائيًا) + فورمات إنشاء ذاتية لتقارير يومية/فحوصات جودة وسلامة/طلبات توريد |

## حسابات المقاولين (يديرها الموظفون الداخليون)

| الشاشة | ماذا تفعل |
|---|---|
| `Contractors/Index` | جدول حسابات دخول المقاولين مُرقَّم |
| `Contractors/Create` | فورم بسيط: اسم/شركة/هاتف/بريد (دخول البوابة)/كلمة مرور |

## شاشات عامة (لا تتبع وحدة واحدة)

| الشاشة | ماذا تفعل |
|---|---|
| `Home/Index` | صفحة هبوط للزوار، ترحيب+توجيه للوحة حسب الدخول |
| `Home/Dashboard` | لوحة المدير/الشركة — ٥ وحدات مستقلة كل منها تظهر حسب صلاحية منفصلة (نظرة عامة، مشاريع، مواقع، تكليفات، تحليلات مراحل) |

## ملاحظات جرد إضافية

- `DesignProposalsController` و`ProjectDocumentsController` **بلا مجلد Views** إطلاقًا — كل تصرفاتهما POST فقط تعيد التوجيه لصفحة أخرى (أجزاء من صفحات أكبر، وليستا شاشتين مستقلتين).
- `Admin/EditRole` (GET) مجرد إعادة توجيه فارغة — تعديل الأدوار كله مدمج داخل `Roles.cshtml` نفسها.
