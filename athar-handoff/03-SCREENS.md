# مواصفة الشاشات

كل شاشة تدعم **الإضافة والتعديل والحذف والعرض** ما لم يُنصّ على غير ذلك، وأزرارها في ترويسة الشاشة.
النمط الموحّد لكل شاشة قائمة:

1. **الترويسة**: سطر صغير باسم النظام ورقمه · العنوان · (يساراً) أزرار: عرض · تعديل · حذف · زر الإضافة البنفسجي.
2. **شريط الأرقام**: بطاقات بيضاء بإطار `#ecebf2`، البطاقة الحرجة بإطار ملوّن.
3. **شريط التصفية**: حقل بحث + مرشّحات «… ▾» + **أزرار «+» لإدارة القوائم** (بند L7) — إطار متقطّع بنفسجي.
4. **الجدول**: `display:grid` بأعمدة ثابتة، رأس `#faf9fd`، فواصل `#f6f5fa`.
5. **لوحة تفاصيل** أسفل أو جانب الجدول عند الحاجة.
6. **سطر ترقيم وملاحظة سفلية** تشرح قاعدة العمل.

## قائمة التحقق النهائية

- [ ] الشريط العلوي بلا قائمة إدارات — الشعار والبحث والمستخدم فقط.
- [ ] القائمة الجانبية: وصول سريع + الأنظمة الثمانية بأرقامها وشارات نطاقها، والبند النشط يطابق الصفحة.
- [ ] بنود «لاحقاً» معطَّلة بشارة «قادمة» وليست مخفية.
- [ ] كل شاشة: أزرار عرض · تعديل · حذف · إضافة في الترويسة.
- [ ] كل قائمة خيارات لها زر «+» بجانبها — **ولا شاشة مركزية للخيارات**.
- [ ] المشروع بلا مساحة وسعر متر · فيه التسليم الفعلي · وإجمالي التكلفة **غير قابل للكتابة**.
- [ ] المساحة وسعر المتر في **المرحلة**.
- [ ] رمز المشروع يدوي + تذكير بآخر رمز + فحص تكرار.
- [ ] الأولوية (مستعجل/غير مستعجل) حقل مستقل عن الحالة، في التكليفات والمهام.
- [ ] كرت المهمة كامل، و**عدة مكلَّفين** بصور متراكبة في الجدول.
- [ ] قالب مهام لكل مرحلة قابل للإضافة والتعديل والحذف.
- [ ] موقع الموظف: خريطة + تحديد تلقائي + قابل للتعديل + نطاق.
- [ ] إشعار العقد قبل ٣٠ يوماً · إيقاف الحساب · واسترجاع البيانات عند التجديد.
- [ ] الصيانة في ٠٣ والعهد في ٠٦ — منفصلتان.
- [ ] «الموظفون» لا «المستخدمون» في كل مكان.
- [ ] «تكليفات المشروع» لا «تكاليف المشروع».
- [ ] كلمة المرور: ٨ خانات + ظهور + شروط الأمان.
- [ ] المهندسة ترى تكليفاتها فقط — والتصفية في الاستعلام.
- [ ] المطالبة المالية لا تُحوَّل قبل الاعتمادين.
- [ ] المقترح المرفوض محفوظ بسببه.
- [ ] الأرقام `tabular-nums` · العملة «د.ل» · الأكواد لاتينية · الاتجاه RTL.
